ตรวจการตั้งค่าเว็บไซต์

ส่ง HTTP HEAD request เพียงครั้งเดียว เพื่อตรวจ security headers ที่ browser อ่านได้ ไม่มีการ crawl หรือทดสอบช่องโหว่เชิงโจมตี

ต้องได้รับอนุญาตจากเจ้าของระบบก่อนใช้งาน Browser อาจปฏิเสธการอ่านผลจากเว็บไซต์ที่ไม่เปิด CORS และไม่สามารถตรวจคะแนน/รายละเอียดใบรับรอง TLS ได้

วิเคราะห์ซอร์สโค้ด

การวิเคราะห์นี้เป็นกฎพื้นฐาน ไม่ใช่ SAST เต็มรูปแบบ ผลที่พบเป็นเพียงจุดเริ่มต้นสำหรับการตรวจสอบด้วยคน

ตรวจสอบ dependency

อัปโหลด package-lock.json หรือ package.json เพื่อตรวจหาช่องโหว่ที่มีบันทึกใน OSV (Open Source Vulnerabilities)

จะส่งเฉพาะชื่อแพ็กเกจและเวอร์ชันไปยัง OSV เพื่อค้นหาข้อมูลช่องโหว่ ไม่ส่งไฟล์หรือ source code ทั้งหมด ช่วงเวอร์ชัน เช่น ^1.2.3 ต้องใช้ package-lock.json เพื่อให้ตรวจได้แม่นยำ

สแกนในเครื่อง (ไม่อัปโหลดไฟล์)

ใช้ Microsoft Defender Antivirus บน Windows ตรวจไฟล์ที่คุณเลือก โดยไฟล์ต้นฉบับไม่ถูกส่งเข้าเว็บไซต์หรือ Backend

ตัวช่วยทำงานบนเครื่อง Windows ของคุณเอง ใช้ได้เมื่อ Microsoft Defender Antivirus เปิดใช้งานอยู่ ตัวช่วยจะไม่ส่งไฟล์หรือ path ไปยังเซิร์ฟเวอร์ แต่ Defender อาจกักกันหรือลบภัยคุกคามตามการตั้งค่าของ Windows
  1. ดาวน์โหลดตัวช่วยสแกนไวรัสในเครื่อง
  2. เปิด PowerShell ในโฟลเดอร์ที่ดาวน์โหลด แล้วเรียกคำสั่งด้านล่าง จากนั้นเลือกไฟล์ในหน้าต่างที่เปิดขึ้น
  3. เลือกไฟล์รายงานที่ตัวช่วยสร้าง แล้วกดวิเคราะห์เพื่อดูจำนวนไฟล์ ผลตรวจพบ และไฟล์ที่สแกนไม่สำเร็จ
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\virus-scan.ps1"

ตรวจสอบ Wi-Fi ที่เชื่อมต่ออยู่

ตัวช่วย Windows อ่านชื่อเครือข่ายที่เชื่อมต่อ, คุณภาพสัญญาณ และชนิดการยืนยันตัวตน/การเข้ารหัสจากคำสั่ง netsh wlan แล้วบันทึกรายงานไว้ในเครื่อง

เว็บไม่สามารถอ่านข้อมูล Wi-Fi จากเบราว์เซอร์ได้โดยตรง จึงต้องดาวน์โหลดและเรียกใช้ตัวช่วย Windows ด้วยตนเอง การตรวจนี้อ่านเฉพาะเครือข่ายที่เชื่อมต่ออยู่ ไม่สแกนเครือข่ายรอบข้าง และไม่ส่งรายงานไปยังเซิร์ฟเวอร์
  1. ดาวน์โหลดตัวช่วยตรวจ Wi-Fi สำหรับ Windows
  2. เปิด PowerShell ในโฟลเดอร์ที่ดาวน์โหลด แล้วเรียกคำสั่งด้านล่าง (เป็นการอนุญาตเฉพาะการเรียกครั้งนี้) ระบบจะสร้าง wifi-scan.json บน Desktop
  3. เลือกไฟล์รายงานด้านล่างเพื่อแสดงระดับสัญญาณและประเมินความเสี่ยง
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\wifi-scan.ps1"
ผลประเมินดูเฉพาะการตั้งค่าการยืนยันตัวตน/การเข้ารหัสที่ Windows รายงาน ไม่ใช่การยืนยันว่าเครือข่ายปลอดภัยทั้งหมด ความแข็งแรงรหัสผ่าน, WPS, firmware, การตั้งค่า router และอุปกรณ์อื่นในเครือข่ายตรวจไม่ได้จากเครื่องลูกข่าย
